ไฟล์ในชุดนี้ (ห้ามเปลี่ยนชื่อไฟล์ และต้องวางรวมกันในโฟลเดอร์เดียว ชั้นบนสุดของเว็บ)
  index.html              หน้าแอปหลัก ฝังระบบ Apps Script ไว้ด้านในแบบเต็มจอ
  manifest.webmanifest    ข้อมูลแอป: ชื่อ ไอคอน สี ทางลัด การรับไฟล์ที่แชร์
  sw.js                   Service Worker: เปิดแอปเร็ว หน้าออฟไลน์ รับไฟล์ที่แชร์
  offline.html            หน้าที่แสดงเมื่อไม่มีอินเทอร์เน็ต
  icon-192.png / icon-512.png / icon-maskable-512.png   ไอคอนแอป
  apple-touch-icon.png    ไอคอนสำหรับ iPhone / iPad
  favicon-32.png          ไอคอนแท็บเบราว์เซอร์
  README.txt              ไฟล์นี้ (จะอัปโหลดด้วยหรือไม่ก็ได้)

ขั้นตอนแบบย่อ (ดูคู่มือฉบับเต็มในเอกสารคู่มือการติดตั้ง หัวข้อ "ติดตั้งเป็นแอป PWA")
 1) สร้าง repository แบบ Public บน GitHub เช่นชื่อ ttm-opd
 2) Add file → Upload files → ลากไฟล์ทั้งหมดในโฟลเดอร์นี้ไปวาง → Commit changes
 3) Settings → Pages → Build and deployment: Source = Deploy from a branch,
    Branch = main และโฟลเดอร์ / (root) → Save แล้วรอ 1–10 นาที
 4) จะได้ที่อยู่ https://<ชื่อบัญชี>.github.io/ttm-opd/
 5) ในระบบ: กด 🛡️ สำหรับเจ้าหน้าที่ (ชื่อผู้ใช้ admin) → 📲 แอป PWA → วางที่อยู่ข้อ 4 → บันทึก
 6) เปิดที่อยู่ข้อ 4 บนมือถือหรือคอมพิวเตอร์ แล้วกด "ติดตั้ง" / "เพิ่มไปยังหน้าจอโฮม"

ข้อควรรู้ด้านความปลอดภัย
 - ชุดไฟล์นี้ไม่มีข้อมูลผู้รับบริการ ไม่มีรหัสผ่าน และไม่มี API Key
   มีเพียงลิงก์ Web App ชื่อแอป สี และไอคอน
 - ระบบจะยอมทำงานภายในแอปนี้เฉพาะเมื่อเปิดจาก "ที่อยู่แอปที่ลงทะเบียนไว้" ในหน้า Admin เท่านั้น
 - เว็บทุกเว็บภายใต้ https://<ชื่อบัญชี>.github.io ใช้พื้นที่เก็บข้อมูลเบราว์เซอร์ร่วมกัน
   จึงควรใช้บัญชี GitHub หรือ Organization ที่ใช้เฉพาะแอปนี้ และห้ามวางหน้าเว็บอื่นเพิ่ม
 - เมื่อเปลี่ยน WEB_APP_URL, ชื่อแอป, สีธีม หรือโลโก้ ให้ดาวน์โหลดชุดไฟล์ใหม่แล้วอัปโหลดทับไฟล์เดิม
